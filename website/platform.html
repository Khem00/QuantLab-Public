CAPABILITY CATALOG

What the code supports today.

The following descriptions are based on the current repository implementation, not on aspirational product language.

01

Data ingestion & integrity

Load supported local CSV datasets, normalize source layouts to a canonical Date/Symbol/OHLCV schema, validate structure and values, and assess data trust.

Data Trust details →
02

Financial features

Calculate SMA20/SMA50, EMA20/EMA50, RSI14, 10- and 30-day momentum, returns, rolling annualized volatility, and drawdown-related measures.

03

Strategies & signals

Use the registered buy-and-hold, RSI, and SMA crossover strategies. Validate signal series against explicit input contracts.

04

Backtesting

Run chronological signal-based simulations with a next-bar execution convention, initial capital, position sizing, commission, and slippage assumptions.

05

Portfolio & risk

Calculate portfolio equity and returns, volatility, Sharpe ratio, maximum drawdown, and trade statistics. Allocation utilities include equal weighting and weight normalization.

06

Experiments & comparison

Configure repeatable experiment runs and compare registered strategies across validated datasets using common execution and result structures.

07

Chronological validation

Separate development and holdout periods without shuffling, retain warm-up context for indicators, and neutralize pre-boundary signals for a fresh holdout portfolio.

08

Reporting & evidence

Generate equity, return, drawdown, and strategy-comparison charts; export summaries; create Markdown reports and structured evidence packs with SHA-256 checksums.

IMPORTANT BOUNDARY

Research infrastructure,
not a trading terminal.

QuantLab's current scope is historical, rules-based research. It does not provide live trading execution, broker or wallet connectivity, custody, live market-data service, public API, general-purpose optimizer, or personalized investment advice.

Data availability, licensing, source provenance, transaction costs, and execution realism remain material constraints in any real-world evaluation.
