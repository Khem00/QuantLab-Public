QuantLab uses AI as an engineering and research assistant around a deterministic, testable financial-research workflow — not as an autonomous trading authority.

AGENT-READABLE WORKFLOW

Evidence-first backtest audit.

The repository includes an agent-readable skill describing a workflow for systematic strategy backtest validation and reproduction. It guides an agent to inspect inputs and assumptions, reproduce supported rules, check timing and costs, review metrics and holdout results, and preserve structured evidence.

The skill documents a workflow; it does not itself create new runtime capabilities or grant execution authority.

SEPARATE COMPANION INTEGRATION

Quantitative result reproduction via MCP.

A separately deployed companion service exposes a constrained reproduction tool over MCP. It is not the same thing as the QuantLab-Public Python package, and it should not be mistaken for a general public QuantLab API.

SEPARATE DEPLOYMENT

QuantLab Reproduction MCP

Accepts a dataset URI and SHA-256, a supported strategy and metric, a claimed value and tolerance, and a specification. The supported strategy specifications are buy-and-hold, SMA crossover, and RSI with defined defaults; annualization is constrained to 252 in the current service.

Outcomes distinguish MATCH, MISMATCH, INVALID_SPECIFICATION, UNABLE_TO_REPRODUCE, and INTERNAL_ERROR.

Open companion service ↗

The companion service may cold-start. Its supported contract is narrower than the full QuantLab research platform. A MATCH is conditional on the declared specification and available implementation; it is not independent certification of a strategy or data source.

FEEDBACK INCORPORATED

Specification before numerical comparison.

Following external feedback on reproducible Sharpe verification, the companion reproduction workflow was tightened to validate the specification before comparing a claimed numerical result.

Why this matters

If a request describes conflicting conventions — for example, an annualization factor inconsistent with the supported calculation — the correct response is to reject or qualify the specification before reporting a numerical match. A number that happens to be close is not enough.

The central specification-validation concern was acknowledged by the reviewer, but the reviewer did not independently certify the updated implementation.
