CURRENTLY IMPLEMENTED

Available in the Python research codebase.

  • Canonical OHLCV normalization, validation, and Data Trust assessment.
  • Financial features including moving averages, RSI, momentum, returns, and volatility.
  • Registered buy-and-hold, RSI, and SMA crossover strategies.
  • Deterministic historical backtesting with declared next-bar timing and cost parameters.
  • Portfolio equity, returns, risk metrics, and trade statistics.
  • Strategy experiments and comparisons, charts, CSV exports, Markdown reports, and evidence packs.
  • Chronological development/holdout workflow with warm-up context.
  • Automated tests and an agent-readable backtest audit workflow.
LIMITED / SEPARATE / REQUIRES CARE

Do not overstate the current system.

LIMITED SCOPE

Data coverage

Local supported CSV datasets are not a live data service. Source provenance, licensing, and completeness must be checked for each use.

SEPARATE SERVICE

MCP reproduction

The deployed MCP reproduction service is a companion integration with a narrower contract, not the full platform or a general API.

ENGINEERING REQUIRED

Client-ready pilot

The pilot specification identifies further work around canonical loading, source quality, manifests, baselines, multi-symbol semantics, and full regression review.
